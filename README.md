# HTML Learning Project

Website statis untuk tugas belajar HTML, dibuat dengan Bootstrap.

## Demo online

Workflow GitHub Actions akan menerbitkan website ke GitHub Pages setiap kali ada push ke branch `main` atau `master`.

1. Push project ke repository GitHub.
2. Buka **Settings → Pages**, lalu pilih **GitHub Actions** sebagai build and deployment source.
3. Buka tab **Actions** dan tunggu workflow **Deploy website to GitHub Pages** selesai.
4. Salin tautan website dari hasil deployment untuk dibagikan kepada dosen.

Alamat demo biasanya berbentuk `https://USERNAME.github.io/NAMA-REPOSITORY/`.
