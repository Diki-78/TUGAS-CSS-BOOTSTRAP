01

HTML fundamentals

HTML (HyperText Markup Language) is the standard markup language for creating web pages. Think of it as the structure that gives every website its content and meaning.

What does HTML mean?

  • HyperText — text that can connect to other pages.
  • Markup — annotations that describe content and structure.
  • Language — a set of rules for creating web content.

How tags work

Tags are keywords wrapped in angle brackets. Most come in pairs: an opening tag and a closing tag.

<h1>A page heading</h1>
<p>A paragraph of text.</p>
02

A basic HTML document

Every HTML page starts with a document type, metadata, and a body for visible content.

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My first page</title>
  </head>
  <body>
    <h1>Welcome to my website</h1>
    <p>This is my first paragraph.</p>
  </body>
</html>
<!doctype html>

Declares an HTML document.

<html>

Wraps the whole page.

<head>

Holds page metadata.

<body>

Holds visible content.

Useful attributes

Attributes add information to an element and are written inside its opening tag.

<img src="photo.jpg"
     alt="A mountain at sunrise"
     width="300">

<a href="https://example.com"
   title="Visit Example">Visit</a>
  • id — a unique identifier.
  • class — a reusable grouping for styling.
  • src and href — resource and link addresses.
  • alt — a text alternative for an image.
